# API (gerada)

Estas páginas são geradas a partir das docstrings do pacote `market_opentes`
pelo [mkdocstrings](https://mkdocstrings.github.io/), a cada build da
documentação.

| Página | Módulos | O que tem |
|---|---|---|
| [Caso e cenários](case.md) | `config`, `scenarios` | o caso, a faixa de tensão, as chaves do armazenamento e a redução de cenários |
| [Modelos](models.md) | `optimization` | os modelos do prosumidor, do concentrador e do operador |
| [Negociação e operação](negotiation.md) | `dual`, `operation` | a decomposição dual e a fase de operação |
| [Liquidação](settlement.md) | `settlement` | transações, DLMP e flexibilidade |
| [Figuras](figures.md) | `figuras`, `figuras_mensagens` | as figuras de uma execução |

Os comentários citam as equações da tese de referência pelo número, como (6.25);
a formulação completa está em [O modelo de mercado](../../explanation/market-model.md).
