# tteso-market-opentes
Repositório do time **TTESO** do projeto [OpenTES](https://github.com/grei-ufc/general-opentes), do Grupo de Redes Elétricas Inteligentes (GREI) da UFC. Aqui fica o **modelo do mercado transativo**: os modelos de otimização de cada agente, a decomposição dual que os coordena, a fase de operação, a liquidação e as figuras de resultado.
